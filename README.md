# far2mtp
FAR Manager 2 plugin for transferring files to Android via MTP

FarMTP — плагин для Far Manager 2.0 (x64): телефоны Android по MTP
=====================================================================

Плагин открывает в панели Far телефоны, планшеты и другие MTP-устройства —
то же, что видно в Проводнике в «Этот компьютер». Работает через штатный
механизм Windows (Windows Portable Devices), поэтому на телефон ничего
ставить не нужно, отладка по USB и ADB тоже не нужны.

УСТАНОВКА
---------
1. Закройте Far.
2. Создайте папку  <папка Far>\Plugins\FarMTP
3. Положите в неё FarMTP.dll
4. Запустите Far.

ПОДКЛЮЧЕНИЕ ТЕЛЕФОНА
--------------------
1. Подключите телефон кабелем и разблокируйте экран.
2. В шторке уведомлений нажмите «USB...» и выберите «Передача файлов»
   (File transfer / MTP). В режиме «Только зарядка» устройство не видно.
3. Проверка: если телефон виден в Проводнике — его увидит и плагин.

ИСПОЛЬЗОВАНИЕ
-------------
Alt+F1 / Alt+F2  → пункт «MTP: телефоны и планшеты»
F11              → тот же пункт в меню плагинов
Командная строка:  mtp:                          — список устройств
                   mtp:Pixel 7\Внутренний общий накопитель\DCIM  — сразу в папку

Внутри панели:
  Enter        — войти в устройство / хранилище / папку
  F3 / F4      — просмотр / редактирование (после сохранения в F4 файл
                 автоматически записывается обратно на телефон)
  F5 / F6      — копирование / перемещение (в обе стороны, вместе с папками)
  Shift+F6     — переименование
  F7           — создать папку
  F8           — удалить (безвозвратно: корзины на телефоне нет)
  Ctrl+R       — перечитать папку
  Esc          — прервать копирование

Структура: Устройство → Хранилище («Внутренний общий накопитель», «SD-карта»)
→ папки. Копировать на устройство и создавать папки можно только внутри
хранилища.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
* «MTP-устройства не найдены» — телефон заблокирован или не выбран режим
  «Передача файлов». Переподключите кабель и выберите режим заново.
* Устройство есть, но внутри пусто — разблокируйте телефон и нажмите Ctrl+R.
  Android скрывает файлы, пока экран заблокирован.
* Ошибка при открытии устройства — закройте другие программы, которые
  могут держать телефон (Samsung Smart Switch, Windows Photos и т. п.).
* Большие папки (DCIM с тысячами фото) открываются заметно дольше обычных:
  это ограничение протокола MTP, Проводник тоже работает медленно.
* Время файлов: MTP передаёт дату изменения не на всех устройствах.
  При копировании на телефон дата обычно ставится текущая.
* Проверено на этапе сборки. На вашем железе плагин ещё не запускался —
  если что-то пойдёт не так, пришлите текст ошибки из окна Far.

СБОРКА ИЗ ИСХОДНИКОВ
--------------------
Папка src: FarMTP.cpp — весь код плагина.
  build_msvc.bat  — Visual Studio (x64 Native Tools Command Prompt)
  build_mingw.sh  — MinGW-w64
plugin.hpp — заголовок API Far 2.0 (из исходников Far, сборка 1761/1807).
portabledevice*.h — заголовки WPD из MinGW-w64 (для MSVC берутся из Windows SDK).
